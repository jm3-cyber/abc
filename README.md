# MATERIALES DEL CURSO DE ASPECTOS BÁSICOS DE LA COMPUTACIÓN

En este repositorio podrán encontrar los siguientes materiales:

* Una guía resumida de comandos de Git (en git.md)
* Una guía resumen del formato Markdown, que se emplea para documentación en
  Github (en Markdown.pdf)
* Algunos ejemplos de HTML y CSS (en primera.html, segunda.html y estilos.css).

Espero que el material pueda serles de utilidad para referencia y estudio.
