# TERCER EXAMEN PARCIAL - GIT Y GITHUB

Este examen es práctico, y evalúa su proficiencia en el uso de Git y Github.

La siguiente es la lista de actividades a realizar

* Cree un repositorio local llamado `examen_3`. Configúrelo para que
  las contribuciones aparezcan a nombre suyo.
* Cree un archivo llamado `README.md` que muestre el título "Tercer examen
  parcial" en letras grandes. En letra normal, escriba sus nombres y apellidos.
* Grabe el archivo `README.md` y haga un commit al repositorio con un comentario
  adecuado.
* Cree un repositorio en Github con el mismo nombre del repositorio local.
  Márquelo como privado, y especifique al profesor (jm3-cyber) como
  colaborador. De esta manera, el profesor podrá revisar y calificar su trabajo.
* Haga un push del repositorio local a Github. Verifique que el `README.md`
  se vea con el formato correcto. De no ser así, corrija el archivo localmente,
  y vuelva a hacer commit y push.
* Agregue al repositorio local un programa en Python que imprima tres marcas de
  automóviles en pantalla. Haga un commit con un comentario adecuado.
* Agregue al programa una nueva marca de automóvil y un comentario. Efectúe
  otro commit.
* Agregue al programa dos nuevas marcas de automóviles, y borre la primera.
  Efectúe otro commit.
* Agregue al repositorio un archivo llamado `aprendizajes.md`. En él resuma los
  principales aprendizajes que tuvo en el curso. Incluya dos tipos de
  encabezados, una lista de tareas, una tabla con tres columnas y por lo menos
  cuatro filas, y dos emojis. Efectúe un nuevo commit.
* Haga un push del repositorio local a Github. Verifique que todos los archivos
  suban bien.
* Modifique en línea el archivo `aprendizajes.md`, agregando un trocito de
  código en Python. Haga commit de los cambios.
* Localmente, haga un pull de los cambios que hizo remotamente.
* Adicione un archivo al repositorio local llamado `commits`, que contenga un
  pantallazo del log de commits de su repositorio local (la extensión del
  archivo `commits` dependerá del formato que su sistema operativo emplee
  para guardar las capturas de pantalla). Haga el commit respectivo.
* Finalmente, modifique el archivo `README.md`, poniendo al final la hora de
  finalización de este ejercicio. Haga el commit respectivo, y haga un push
  del repositorio local a Github.

Muchos éxitos... ¡que la fuerza te acompañe!
